# 蛊道修仙：青茅山

Godot 4.3 / GDScript / GL Compatibility。当前是按《蛊真人》具体规则校正的青茅山自由探索试玩；主打自主游历、供养与修炼，不强制复演小说剧情。

## 启动

用 Godot 4.3 导入本目录的 `project.godot` 后按 F5。终端运行时，在仓库根目录把示例路径替换成实际引擎路径：

```powershell
$godotExe = 'C:/Tools/Godot/Godot_v4.3-stable_win64_console.exe'
& $godotExe --headless --editor --path ./godot --import
& $godotExe --path .\godot
```

新规则使用 `user://canon_save.json`。原 `save.json` 保留，未自动迁移。启动时继续新规则存档，死亡可读取最近保存。暂停菜单的“重置存档”只针对新文件。

## 开局与用养炼

开局为一转初阶、丙等 44% 元海，携带一只未炼化月光蛊。R 开始炼化，真元不足时可吸收元石。第一只炼化蛊成为本命蛊；在 Q 页管理居处及 1/2/3 绑定。

I 是外部行囊：元石、蛊食、绷带、材料、未炼化蛊及外部携带蛊。Q 是空窍与已炼化蛊管理：元海、窍壁、精炼真元、蛊虫居处。三个快捷键不是三个空窍或拥有数量上限。

| 蛊 | 取得方式 | 用途 | 食物 |
| --- | --- | --- | --- |
| 月光蛊 | 开局外部携带，先炼化 | 月刃；初阶每次一成真元 | 月兰花瓣，每天四片 |
| 酒虫 | 带青竹酒进入后山石缝，靠近内部酒香处按 E；一次性 | 两成普通真元换半成高一小阶真元；一转巅峰/二转不适用 | 一坛青竹酒供四天 |
| 玉皮蛊 | 古月商铺的单只库存，500 元石，先炼化 | 持续耗元，受击另耗，断供失效 | 二两玉石供十天 |

花瓣/酒按核对价格售卖。玉皮库存、价格及猎获/材料回收是试玩安排，不是原著剧情。商铺“出售猎获与材料”进入背包出售，可维持供养，不要求杀怪升级。错误食物不会扣除；饿死后不能喂醒，本命蛊死亡会反噬。

J 打坐调动真元温养窍壁，温养满后 Q 冲关。一转初→中→高→巅峰可试玩；跨转冲窍尚未开放。升小阶不增加肉身攻击或治疗身体；击杀、捕获、炼化不提供修行经验。

## 地图、交互与人体

- 地图从 80×60 扩至 **160×120 格 / 5120×3840 像素**，面积四倍。东麓溪谷、远山高岭、南麓林地以环形山路和木桥相连。
- 新增九处自由探索点：东麓竹坳、溪谷渡口、远山观景台、东南石滩、南麓竹坡、山民歇脚棚、杉林深潭、南山石径、溪边营地。名称/坐标是游戏设计；不设主线任务、击杀数或转数门槛。
- 在探索点按 E：竹坳/竹坡拾木料，石滩/石径拾碎石，各 3 份、180 秒室外游玩冷却。营地打开歇脚菜单，可领取一次绷带 ×2 和青竹酒 ×1、用真实绷带处理紧急伤口、查看身体/背包/游历记录，或就地打坐。包扎优先止血，毁损部位不会再生。
- 当前正式开放的月光蛊、酒虫、玉皮蛊全部采用原创生成的透明插画，统一接入背包、空窍清单及元海示意、图鉴、快捷栏、蛊术、炼化、商铺和密洞。月光为蓝色月牙晶体，酒虫为白胖蚕形；玉皮外观结合皮蛊同系和翠绿护体效果作美术推导，详见 CREDITS。未宣称完成全书所有蛊种。
- M → 游历记录：记录九处探索点的到访、材料恢复和营地补给；可点击已知地点设置步行目的地。地图看见地点后仍需靠近按 E，才算踏查完成。
- HUD 使用紧凑状态条、144×108 小地图、48 像素技能框；日志短暂显示。F1 可进一步收起。修行录居中并限制到 1080×580 逻辑像素，内容仍可滚动。

- 古月药堂、商铺、竹楼、学堂、祠堂，白家/熊家会客楼，后山密洞、地下溶洞，共九处入口。门前 E 进入，室内南侧 E 离开。
- 青矛竹、树木、山体、溪瀑和梯田；地点关系有章节依据，距离和未明确朝向为缩尺布局。
- 房屋、树冠和山体遮挡人物时渐隐。M 可设步行目的地；五域示意只用于查阅。
- 眼伤连续缩小视野；缩放不扩大实际探测距离。地图记录探索，视野外目标隐藏。
- NPC 可受击、敌对和死亡；敌对或死亡的服务人物停止服务，状态保存。
- 树木、石块、建筑和屋内家具/墙壁可受损；破坏掉落进入背包并清理对应碰撞。山体有硬度门槛，当前普通攻击不足以破坏；地表与水体不可挖空。
- B 页有可点击的人体图、15 组部位、具体后果、出血/疼痛/意识与治疗建议。左右按人物自身区分。
- 未毁损伤处在停止受击、止血后随时间恢复；毁损部位不再生。药堂只提供包扎，普通材料不能当绷带。
- V 页解释实际蛊术与消耗；已退役任意元素自动组合公式，小光等组合尚未开放。

## 可选山寨委托

在古月商铺或学堂交谈，选择“山寨委托”；也可从 M 山志查看进度。接取、交付需身在商铺/学堂，且服务人物存活、未敌对、建筑未毁。柜台外只能查阅和标记路线。委托无时限，不限制自由探索；先前的踏查同样有效，也不奖励修为。

| 委托 | 条件 | 报酬 | 再接条件 |
| --- | --- | --- | --- |
| 竹楼修缮 | 交付木料 ×6 | 元石 10、月兰花瓣 ×10 | 300 秒游玩冷却 |
| 山路补石 | 交付碎石 ×6 | 元石 10、绷带 ×2 | 300 秒游玩冷却 |
| 东麓踏查 | 到访东麓竹坳、溪谷渡口、溪边营地 | 元石 45、青竹酒 ×2 | 一次性 |
| 南麓访踪 | 到访南麓竹坡、山民歇脚棚、南山石径 | 元石 50、绷带 ×3 | 一次性 |
| 青茅山行记 | 到访全部九处野外探索点 | 元石 120、玉石（二两）×2 份 | 一次性 |

这些委托与奖励是自由探索试玩安排，不是原著剧情事件。普通菜单和离线不推进冷却，领取记录存档，重复点击或读档不能再领一次性报酬。

## 保存与范围

保存空窍、两种真元、温养、蛊虫 ID/居处/快捷位/本命、饥饿、物品、身体、NPC、环境破坏、探索、目标点和镜头缩放。version 6 增加委托接取、完成次数和冷却，保留 version 5 的室内/野外站位、探索点、采集冷却、营地领取和 HUD 偏好。旧 version 5 默认没有已接委托；旧 version 4 从山寨继续，并将 80 格行宽的迷雾记录转为新地图索引。继续游戏恢复安全站位；没有联机同步。

普通菜单暂停，炼化窗口工作时推进炼化、回元和已炼化蛊饥饿；离线不耗食物。完整身体生理、未炼化蛊喂养、两天/仙窍空间、跨转、完整三寨内容及五域均待开发；剧情不作为开放探索的前置要求。美术是临时素材，尚非原著建筑的完整复原。全部模拟参数与未完成项见 CANON。

## 验证

从仓库根目录执行；脚本为每个检查创建独立工程与独立用户数据目录，避免覆盖玩家存档。用 `--godot` 指定实际引擎路径；省略时仅尝试开发环境的默认路径：

```powershell
python -X utf8 tools/check_docs.py
python -X utf8 tools/check_game.py --godot $godotExe --checks canontest
python -X utf8 tools/check_game.py --godot $godotExe --checks canontest --screenshots aperture bag journal map worldmap waterfall cave --resolution 1280x720
python -X utf8 tools/check_game.py --godot $godotExe --checks canontest perftest --screenshots aperture journal --resolution 960x540
```

结果保存在 `.test-runs/时间戳/`，含日志、报告和截图。以 `CANONTEST checked=... failures=[]` 及无脚本错误为准；截图需要打开检查。

旧 `featuretest`、`polishtest`、`probe`、`bagtest`、`skilltest`、`test_hunger.tscn` 等包含退役规则，不能用其历史通过结果证明当前版本。正式回归入口是 `canontest`。详细记录见 VALIDATION。

## 开发入口

`Main.gd` 为运行主控，`GameData.gd` 为三种正式蛊数据，`GuArt.gd` 统一配图，`ApertureState.gd` 为修行模型，`GuVirtual/GuManager` 管实例，`World/WorldProp/HouseInterior/DestructionSystem` 管地图，`CommissionLedger.gd` 管可选委托结算，`VillageUI/MiniMapUI` 管柜台、营地和游历记录，`JournalUI` 管联动页面，`BodyComponent/BodyDiagram/BodyUI` 管身体。

根目录 `AGENTS.md` 和 `.agents/skills/` 为项目协作与技能说明。旧设计稿仅作历史参考；当前用户要求及已核对正文优先。
