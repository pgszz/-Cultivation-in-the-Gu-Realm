# 人物总览与状态条

更新：2026-11-20。当前入口为左上角角色头像、头像旁“人物”或 C。界面采用本项目人物外观和配色；属性、效果与环境倍率来自当前游戏状态。

## 操作

- 左上角集中显示角色外观、姓名、境界、气血、真元和体力。点击头像进入人物总览。
- 小按钮直接打开人物、空窍、身体、背包、山志、蛊术、炼蛊。减号或 F1 收起资源条，保留头像、所有快捷按钮与状态条；加号展开。收起偏好沿用角色存档的 `hud_hidden`。
- 增益使用绿色、减益使用红色，并保留文字分类。每类显示两项简要数值，额外项目通过 `+数量` 进入完整明细；悬停可看效果、持续条件与剩余时间，点击直接定位状态明细。
- 人物总览左侧为身份、资源和身体指标，右侧为“基础 → 当前”、增减来源、修行信息与完整状态列表。内容可滚动。菜单暂停游戏时间，关闭后继续；受伤昏迷期间仍可查看信息。
- 视野人物卡片从角色信息块右侧排列，避免挡住快捷按钮。背包、空窍和三个催蛊快捷位仍各自负责原来的数据。

## 数值口径

| 信息 | 显示规则 |
| --- | --- |
| 徒手攻击 | 肉身基础 + 豕蛊永久力量 + 临时攻击 + 蛮力天牛；显示基础威力，不承诺每击固定扣血 |
| 移动速度 | 基础与平加后，依次结算身体、逐风、水域、湿地、坡度/地下和疾步倍率；列出每步实际增加或减少多少像素/秒，昏迷显示 0 |
| 攻击速度 | 使用普攻实际冷却的身体倍率下限，列出出手间隔；昏迷另标无法行动 |
| 精准度 | 显示眼伤、疼痛、失血与昏迷后的最终值；加减使用“百分点”，最终下限 15% |
| 视野 | 当前层基础半径 + 萤瞳加成，再乘眼部倍率，与迷雾实际半径一致 |
| 护体和护盾 | 护体显示有真元条件的百分比减伤、维持与受击耗元；护盾显示剩余可吸收量。庇护同伴不算作自身减伤 |
| 真元存量 | 当前点数 / 容量；充满比例以个人容量为分母，资质占空窍比例单列，不把 44% 误显示为仅有四成蓝 |
| 真元成本 | 按当前转数/小阶的普通真元折算；精炼真元优先以双倍效力抵扣 |
| 出血和持续伤害 | 身体伤口显示身体血量/秒；灼烧、中毒和流血显示单次基础气血伤害与概率触发频率，不冒充固定气血/秒 |
| 采集、隐息和恢复 | 分别显示木材产量变化、敌人侦测距离变化、符合条件时的自然恢复；瞬时治疗不伪装成持续增益 |

例如：基础移速 168，单腿重伤 ×0.7 后为 117.6，逐风 ×1.35 后为 158.76。界面列出伤势 -50.4、逐风 +41.2、最终相对基础 -9.2（显示四舍五入一位小数），不把 -30% 和 +35% 直接相加。

## 实现与验证

[PlayerStatus](scripts/PlayerStatus.gd) 只读汇总属性和状态；`Main._update_player` 与人物页共享其中的移动计算。其他数值读取现有攻击、身体、蛊效与迷雾接口。汇总不另存一套效果数据，读档、换场景、收蛊、耗尽真元或效果消退后按实际状态刷新。

[PlayerHUD](scripts/PlayerHUD.gd) 提供真实按钮与资源条，由 [HUD](scripts/HUD.gd) 管理显示；[CharacterUI](scripts/CharacterUI.gd) 为完整信息页。头像复用玩家自定义纹理，不重复导入 PNG。

回归入口：`python -X utf8 tools/check_game.py --checks statustest --resolution 1280x720 --timeout 150`，另用 `--resolution 960x540` 验证小窗口。测试隔离工程和角色数据，覆盖展开/收起按钮、各快捷页、点击不攻击、滚轮不缩放世界、真实施法与伤害、叠加数值、到期/断供/切场景、昏迷、读档与只读汇总。实际通过记录见 [VALIDATION](VALIDATION.md)，截图见 [截图索引](screenshots/README.md)。

## 百蛊修炼状态

资质修炼显示每秒容量增长、该蛊上限、终身后天增长已用额度和剩余时长；温养加速显示实际倍率，同时加快耗元。Q 区分先天潜力、后天增长与当前容量，保留小数；不同转数元海对应青铜、赤铁、白银、黄金、紫晶色泽。规则见 [百蛊扩充](../百蛊扩充.md)。

## 肉身蛊效

人物页列出铁骨/玉骨永久改造、锻筋永久进度、各限时状态及代价；攻击速度与移动速度使用战斗中的相同倍率。B 身体页给出选中部位的作用说明。自力更生显示实际恢复速率，受永久豕力与已有筋骨强化影响。全部20种及原著/原创区分见 [肉身专题](../肉身状态蛊.md)。
