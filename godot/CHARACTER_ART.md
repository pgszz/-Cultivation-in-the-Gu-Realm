# 角色设计与 PNG 外观导入

更新：2026-11-18。[游玩说明](README.md) · [美术说明](ART.md) · [验证记录](VALIDATION.md)。

启动后的角色选择页点击 **设计外观**，或在 **新建角色** 弹层中点击 **设计外观 · 衣服与导入图集**，进入“衣冠工坊”。这是玩家角色的外观功能；服装、体型与配色不提供攻击、防御或碰撞优势，也不是原著装备规则。

## 内置设计

- 原画主角继续可用，旧存档缺少外观字段时显示原画。
- 自定义衣装提供短打、交领长衫、对襟外袍；可调衣长、袖宽、身高和体型。
- 可选束发、长辫、披发；衣服、镶边、腰带、裤装、肤色和头发分别选色。
- 左侧预览可切换正面、左侧、背面、右侧，以及站立、行走、攻击、施法、受伤、倒地。人物面板、选角页和实际游戏使用同一套外观。
- 点击“确认外观”保存；取消或 Esc 放弃本次修改。新建流程中的确认只保存草稿，最后仍需输入名字并点击“创建角色”。

## 导入自己的模型图集

本作当前使用 **2D PNG 人物／衣服动作图集**。选择“导入整个人物”可替换完整形象；选择“导入衣服图层”可叠加透明衣装。仅导入衣服时，人物使用内置身体和发型，不会露出原来的长袍。整个人物和衣服也可以同时导入。

| 要求 | 说明 |
| --- | --- |
| 文件 | PNG，透明背景，最大 12 MB |
| 布局 | 6 列 × 4 行，各格为相同大小的正方形 |
| 单格尺寸 | 32–256 像素，例如 768×512（每格 128）或 1536×1024（每格 256） |
| 从上到下 | 正面、左侧、背面、右侧 |
| 从左到右 | 站立、左步、右步、攻击、施法、倒地 |
| 对齐 | 每格保持一致的中心和脚底基线，四周留透明余量，不要带标注、格线或背景 |
| 动作 | 24 格均需有可见内容；受伤使用站姿加后仰与闪色，死亡会过渡到第 6 列 |

导入时检查格式、尺寸、透明背景和空白动作格；不符合要求会显示原因并保留当前外观。静态头像不能代替动作图集，图片本身不会自动生成缺少的动作。

导入图集保留绘制的衣形、配色和身材。使用整身图集时内置造型控件禁用；使用衣服图层时衣形和体型控件禁用，仍可修改内置身体的发型、肤色和裤装颜色。想改导入衣服的轮廓或身材，应在绘图软件中修改对应 24 格再导入。

## 模板与绘制

工坊右侧下滚可找到 **导出人物模板** 和 **导出衣服模板**，输出当前内置设计的 1536×1024 透明 PNG。这两个模板来自同一骨架与动作位置，衣服模板只包含衣装，适合在绘图软件中重画。模板导出始终使用内置设计参数，不会把用户导入的人物误当成可编辑骨架。

仓库也提供可直接编辑的 [人物示例](assets/character_templates/character.png) 和 [衣服示例](assets/character_templates/outfit.png)。模板不带格线，避免把格线误导入游戏；在绘图软件中自行设置 256 像素网格。各格的参考原点为 `(128,208)`，站立脚底约在 `y=228`；以模板实际动作轮廓为准，倒地也必须完整留在自己的格子内。

建议先完成内置体型，再导出人物与衣服两份模板；绘制时保留每格的位置和尺寸。画完用预览逐个方向、动作检查，然后确认。若需缩小文件，可以把整张图等比缩小为 768×512，不能裁掉透明边距或移动单个格子的原点。

## 保存与永久死亡

外观写入角色 version 8 存档的可选 `appearance` 字段。自定义参数直接保存；导入图片确认后复制到 `user://characters/<角色ID>_art/`，文件名由图片内容哈希生成。游戏不再依赖导入时的原始路径。

不同角色各自保存图片；改用其他外观并移除引用后清理旧图片，删除角色时清理该角色图片。取消编辑不留下导入图片。保存失败保留原存档并提示；图片缺失或损坏时显示内置外观，不会破坏背包和世界进度，重新导入可修复图片。

已陨落角色保留外观记录，但“设计外观”和“进入青茅山”均禁用。换装接口同样遵守死亡锁，不能恢复死亡角色。外观功能不改变此前的永久死亡规则。

## 实现与验证入口

[CharacterAppearance.gd](scripts/CharacterAppearance.gd) 用代码绘制可调衣形和四向动作，验证 PNG 并合成纹理；[CharacterArtStore.gd](scripts/CharacterArtStore.gd) 管理角色图片；[AppearanceEditor.gd](scripts/AppearanceEditor.gd) 提供工坊和文件选择器。现有 [ActorAnimation.gd](scripts/ActorAnimation.gd) 继续控制移动、攻击、受伤、死亡和疾步残影，不新增伤害或行动结算。

```powershell
python -X utf8 tools/check_game.py --checks customizetest charactertest controltest arttest --resolution 1280x720 --timeout 180
python -X utf8 tools/check_game.py --checks customizetest --resolution 960x540 --timeout 180
```

`customizetest` 使用隔离工程与存档，完成后启动第二个引擎进程验证外观和死亡状态。通过结果与实际截图检查记录见 [VALIDATION](VALIDATION.md)。
